# Setup responsibilities

The human setup steps in `README.md` have already been completed through the
**Zathura** section, inclusive. Treat those steps as complete; do not repeat them
unless the user requests it.

All setup steps after **Zathura**, starting with **Touchpad Right Click**, are
intended to be automated by agents. When asked to complete the remaining setup,
perform those steps using the repository's configuration files and deployment
tools, following the validation and backup procedures documented in `README.md`.
